LOCALv10.02Python + Android

          
FlowCast

          
24/7 info TV and media player for a local network: images, videos and URL content in one feed on any browser-capable device.

          

            
            
            
            
          

          
    
            
  • Five content sources, per-section shuffle and round-robin interleaving.
    • 
            
  • Automatic AVI/WMV/MOV/MKV → MP4 conversion with FFmpeg and a cache.
    • 
            
  • The same view on TV, desktop and phone — browser only, no app to install.
    • 
            
  • Separate Android app (Flet) for transferring files.
    • 
          

          
  • Python
  • Flask
  • FFmpeg
  • vanilla JS
  • Flet
